# Hi-fi mockups

Nine artboards plus `canvas.json`, extracted from `../exam-planner-screens.html`.

These are *design references*, not the running app — that lives in `design/`.
They were drawn against `prototype/tokens.css` (warm paper, ink navy, ochre
accents, Bricolage Grotesque + IBM Plex), which is a different visual system
from the Steadyline dark/purple tokens the app now uses. Read them for
layout, hierarchy and the platform-fork table, not for colour.
